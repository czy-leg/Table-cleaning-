# 表格清洗助手（Excel & CSV Cleaner）

一个面向普通办公人员、学生和数据处理初学者的本地表格清洗工具。通过简单的网页界面导入 CSV、XLSX 或 XLSM 文件，完成常用清洗操作，并另存为新的 CSV 或 XLSX 文件。

程序在本机运行，不提供登录、云存储、数据库、付费 API、遥测或文件上传功能。原文件不会被覆盖。

## 功能

- 导入 CSV、XLSX、XLSM，Excel 文件可选择工作表。
- 自动尝试 UTF-8、UTF-8 BOM、GB18030 编码。
- 自动识别常见 CSV 分隔符，失败时可手动选择逗号、Tab、分号或竖线。
- 删除完全重复行、完全空白行、完全空白列。
- 清理文本单元格首尾空格，非文本值不强制转换成字符串。
- 按指定列判断重复，并可选择是否区分文本大小写。
- 每次清洗显示原始/结果行数、列数及各项删除数量。
- 导出 CSV 或 XLSX；CSV 可选择 UTF-8 BOM，方便中文 Windows Excel 打开。
- 提供可选的公式注入保护，并可加载内置示例数据。
- 文件只在当前电脑的浏览器和 Python 进程间处理。

## 运行环境

- Windows 10 或 Windows 11（主要支持目标）
- Python 3.10 或更高版本
- 首次安装依赖时需要网络
- 推荐使用项目自带的 `.venv` 虚拟环境

## 从安装 Python 到启动

1. 打开 [Python 官方下载页](https://www.python.org/downloads/)。
2. 下载并安装 Python 3.10 或更高版本。安装时务必勾选 **Add Python to PATH**。
3. 打开本项目文件夹。
4. 双击 `run.bat`。
5. 第一次启动时，脚本会自动创建 `.venv` 并安装依赖，需要等待几分钟。
6. 安装完成后，Streamlit 会启动本地服务，浏览器通常自动打开。若未打开，可访问命令行中显示的 `http://localhost:8501`。
7. 关闭黑色命令窗口或按 `Ctrl+C` 即可停止程序。

后续启动会复用 `.venv`，通常不需要重复安装。

### 手动启动（可选）

在项目目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 使用步骤

1. 先备份需要处理的重要文件。
2. 点击“Browse files”或文件选择区域，导入一个 CSV、XLSX 或 XLSM 文件。
3. CSV 文件如有需要，确认编码和分隔符；Excel 文件选择工作表。
4. 查看原始数据预览和行列数。
5. 勾选需要的清洗操作。所有操作默认关闭，可以任意组合。
6. 点击“执行清洗”，查看结果预览和统计。
7. 选择 CSV 或 XLSX 格式，点击下载按钮。
8. 下载文件默认使用“原文件名_cleaned”命名，并保存在浏览器的下载目录。

没有测试文件时，可点击“加载示例数据”。侧边栏的“重置本次任务”会清除当前文件、选项和结果。

## 清洗规则说明

- “空白”包括缺失值、空字符串、纯空格和 Tab 等仅含空白的文本。
- 删除空白行和空白列时，会按当前所有单元格判断。
- 完全重复行默认区分文本大小写。
- 取消“区分大小写”后，仅对用于重复判断的文本使用不区分大小写的比较。
- 首尾空格清理只处理文本。数字、日期和其他非文本值不会被转换成字符串。
- 删除列后，剩余列保持原有相对顺序。
- 启用“按勾选列删除重复”后，同组记录保留第一次出现的记录。

## 下载与公式安全

CSV 中的文本或列标题如果以 `=`、`+`、`-`、`@`、Tab 或回车开头，使用 Excel 打开时可能被解释成公式。这是 CSV 公式注入风险，尤其需要注意来源不可信的表格。

程序默认保留原始文本，不会悄悄修改。导出前可以勾选“启用公式注入保护”，程序会在危险文本前添加英文单引号，使其作为普通文本显示。该操作会改变文本内容，因此请先确认是否适合你的数据。

把 XLSX 中的公式文本作为公式导出时，公式可能需要 Excel 重新计算；程序本身不会执行上传文件中的宏或代码。

## 已知限制与兼容性

- 支持的扩展名只有 `.csv`、`.xlsx` 和 `.xlsm`。
- 单个文件限制为 50 MB。超过 10 万行时会显示性能提示，但仍可能需要较长时间。
- CSV 只保存单元格值，不保存 Excel 公式、样式、合并单元格或图表。
- 复杂公式、日期显示格式、数字格式、前导零、数据验证、条件格式、图片、图表、批注和合并单元格可能无法完整保留。
- XLSM 的宏不会被读取或执行，也不会被保留。导出结果是普通 `.xlsx` 文件；宏版本请保留原文件备份。
- 加密、损坏、仅修改扩展名的文件可能读取失败。
- Excel 中重复的列标题可能被 pandas 自动改名，复杂表头也可能被当作数据读取。
- CSV 空白行、引号格式和异常分隔符在不同软件中可能有差异，请在下载后复核。
- 程序只做常规数据清洗，不能替代专业数据审计。重要文件务必先备份。

## 隐私与安全

- 不加入遥测、广告、追踪、隐藏网络请求或第三方上传。
- Streamlit 的使用统计已通过项目配置关闭。
- 本地服务只绑定 `127.0.0.1`，不会向局域网开放。
- 不执行上传文件中的宏或代码。
- 不在代码中使用 `eval` 或 `exec` 处理用户数据。
- 不会自动保存或覆盖原始文件。
- `.gitignore` 默认排除虚拟环境、缓存和用户导出的 CSV/XLSX/XLSM 文件，只保留 `samples/sample.csv`。
- 请不要把真实业务数据、密钥或个人信息提交到 GitHub。
